A program that writes the funniest one-line excuse a robot vacuum gives for missing a spot: its lidar mapped the corner as a wall in 2019, and it has never once questioned it.

## Run it

```sh
python3 main.py
```

## The excuse

> My lidar mapped that corner as a wall in 2019 and I have never once questioned it.
